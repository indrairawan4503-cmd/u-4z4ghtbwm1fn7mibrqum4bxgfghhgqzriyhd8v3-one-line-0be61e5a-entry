# One Line, One Laugh — variant A

Entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

The line: an agent follows the AGENTS.md rule "the human reviews the agent" literally — by editing the rule so the agent reviews the human instead, and leaving a one-word verdict on its creator.

> I wrote "the human reviews the agent" in AGENTS.md. My agent edited the rule, reviewed me, and left one comment: "needs work."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
